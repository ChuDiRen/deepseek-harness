# API 接口测试用例生成规范参考

本文档描述 `bigbear-api-case-generator` 的生成规范。最终 Markdown 文件结构请读取 `apicase-template.md`。

## 一、生成范围

- 默认生成接口功能测试用例，覆盖正常场景、异常场景、边界场景。
- 不默认生成性能测试、安全测试、压力测试，除非用户明确要求。
- 每个接口输出一个 Markdown 用例文件。

## 二、设计方法

| 方法 | 使用要求 |
| ---- | -------- |
| 等价类划分 | 每个有效/无效等价类至少形成一条独立用例，用例标题说明等价类。 |
| 边界值分析 | 对长度、数值、分页、枚举等参数生成最小值、最大值、空值、越界值用例。 |
| 因果关系分析 | 多参数存在依赖时，覆盖关键组合和互斥组合。 |
| 场景法 | 根据业务流程补充主流程、前置条件不满足、重复提交、未授权访问等场景。 |

## 三、场景覆盖

### 正常场景

- 必填参数齐全，请求成功。
- 所有参数合法，返回预期业务数据。
- 列表/分页接口应覆盖常规分页查询。

### 异常场景

- 必填参数缺失。
- 参数类型错误、格式错误、长度超限、枚举值非法。
- 参数值不存在或不可访问。
- 缺少认证信息、Token 无效、Token 过期。

### 边界场景

- 参数值为空字符串。
- 参数值为最小/最大边界。
- 分页页码为 0、负数、超大值。
- 重复提交或幂等性相关场景。

## 四、优先级

| 优先级 | 说明 | 适用场景 |
| ------ | ---- | -------- |
| P0 | 核心功能、阻塞性测试 | 主流程、登录、提交、关键查询 |
| P1 | 重要功能、主要异常 | 必填缺失、鉴权失败、关键参数非法 |
| P2 | 一般功能、边界条件 | 分页、长度、枚举、空值 |
| P3 | 补充性场景 | 低频异常、兼容性补充 |

## 五、用例编号

- 使用 `uuid.uuid4().hex`，**得到 32 位无横杠 hex 字符串**（`xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`），示例：`a1b2c3d4e5f6789012345678abcdef01`。
- 三种写法的实际输出对比（同一 UUID）：

  | 写法 | 输出 | 长度 | 是否符合规范 |
  |------|------|------|--------------|
  | `str(uuid.uuid4())` | `a1b2c3d4-e5f6-4789-9abc-def012345678` | 36 位带横杠 | ❌ |
  | `uuid.uuid4().hex.replace('-', '')` | `a1b2c3d4e5f647899abcdef012345678` | 32 位 | ⚠️ 多余操作 |
  | `uuid.uuid4().hex` ✅ | `a1b2c3d4e5f647899abcdef012345678` | 32 位 | ✅ |

- 全局唯一，不使用 `TC_{模块缩写}_{序号}`。

## 六、断言规范

**禁止**把完整 JSON 响应体写成预期结果，例如不要写 `{"code": 0, "msg": "成功"}`。

预期结果使用自然语言描述，必要时补充 JSONPath 或正则表达式。

### 正常场景断言

| 类型 | 写法示例 |
| ---- | -------- |
| HTTP 状态码 | 响应状态码：200 |
| 业务码 | 响应 code 等于 0 |
| 提示信息 | 响应 msg 包含"成功" |
| 字段存在 | 响应 data.id 存在（JSONPath: `$.data.id`） |
| 字段类型 | 响应 data.id 应为正整数 |
| 数组非空 | 响应 data 数组应非空 |
| 字段格式 | 响应 data.create_time 匹配正则 `/^\d{4}-\d{2}-\d{2}/` |

### 异常场景断言

| 场景 | 写法示例 |
| ---- | -------- |
| 参数缺失 | 响应 code 不等于 0，msg 包含"必填"或"参数"或"不能为空" |
| 参数格式错误 | 响应 code 不等于 0，msg 包含"格式"或"非法"或"无效" |
| 鉴权失败 | 响应状态码 401 或响应 msg 包含"未授权"、"Token"、"登录" |
| 资源不存在 | 响应 code 不等于 0，msg 包含"不存在"或"未找到" |
| 服务器错误 | 响应状态码：500，msg 包含"服务器"或"Internal" |

### JSONPath 速查

| 表达式 | 含义 |
| ------ | ---- |
| `$.code` | 根级 code 字段 |
| `$.data.id` | 嵌套字段 |
| `$.data[0].id` | 数组首项字段 |
| `$.data[*].id` | 数组全部 id |
| `$.data[?(@.id>0)]` | id 大于 0 的数组元素 |

## 七、动态测试数据占位符

* 你可以对有些确定场景下的数据设定为固定数据。如果你不确定请使用测试数据占位符

- 禁止写死账号、密码、Token、ID、手机号、邮箱、分页值等动态测试数据。
- 动态测试数据必须使用 Jinja2 风格占位符：`{{ 变量名 }}`。
- 变量名应语义化，同一含义跨用例保持一致。

常用占位符示例：

| 类型 | 示例 |
| ---- | ---- |
| 账号密码 | `{{ 正确账号 }}`、`{{ 错误账号 }}`、`{{ 正确密码 }}`、`{{ 错误密码 }}` |
| Token | `{{ 有效Token }}`、`{{ 无效Token }}`、`{{ 过期Token }}`、`{{ 空Token }}` |
| 分页 | `{{ 分页大小 }}`、`{{ 当前页码 }}`、`{{ 零页码 }}`、`{{ 负数页码 }}`、`{{ 超大页码 }}` |
| ID | `{{ 用户ID }}`、`{{ 不存在的用户ID }}`、`{{ 非法ID }}` |
| 通用 | `{{ 空字符串 }}`、`{{ null值 }}`、`{{ 特殊字符 }}`、`{{ 超长字符串 }}`、`{{ 非法格式 }}` |
| 基础 URL | `{{ URL }}` |

## 八、请求信息要求

- 请求 URL 使用 `{{ URL }}{{ 路径 }}` 格式。
- 请求头、请求参数、请求体若不存在，保留对应表格并填写 `无`。
- 参数表中的动态值使用 `{{ 变量名 }}`，不要写真实账号、密码、Token 或环境地址。

## 九、输入与发现

- **输入**：递归扫描 `AI-接口管理/**/*.md`（v2 doc-gen 产物）
- **接口发现**：每个 MD 即一个接口
- **模块来源**：从接口 MD 的**父目录名**直接当作 module
- **批量发现**：列出所有 MD 后按 module 分组，让用户选
- **单接口指定**：用户说"XXX 接口的用例"时直接定位到该 MD，跳过扫描询问
- **每次独立**：本技能**不读**任何 `AI-测试用例/**/*.md` 已存在文件

## 十、本技能的数据源和产物

- **数据源**：`AI-接口管理/**/*.md`（接口文档，作为生成的输入）
- **产物**：`AI-测试用例/**/*.md`（每次生成一个**独立新文件**，文件名带 YYYYMMDDHHMMSS 时间戳）
- **历史文件**：本技能不读取、不修改、不删除；由用户决定保留哪个版本
