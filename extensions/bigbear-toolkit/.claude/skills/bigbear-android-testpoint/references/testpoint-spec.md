# 安卓 UI 测试点分析生成规范

本文档定义 `bigbear-android-testpoint` 的生成规则。最终页面文档和全局公共模块结构见 `testpoint-template.md`。

## 输入规则

- 本技能默认在**项目根目录**下运行（例如 `WEB功能测试/` 这类某一类测试的根目录,其下直接并列 `AI-信息采集/`、`AI-测试点分析/`、`AI-测试用例/`）；扫描器优先在当前目录定位 `./AI-信息采集`,兼容 `../AI-信息采集`。
- 必须围绕一个明确批次号执行，例如 `20260606-153022`；批次号是 `AI-信息采集/` 下的一级子目录名。
- 用户未指定批次号时，**不要自动跑 `scanner.py --list-batches`**；改为询问用户要分析的批次号。仅当用户明确说"扫一下批次"/"列出批次"时才跑 `--list-batches`。
- 指定批次后，只读取 `AI-信息采集/{批次号}/` 下的 `json/*.json` 和 `img/*`，不要额外读取其他批次。
- 同一批次下可能包含多个模块/功能子目录，全部处理。
- 采集目录统一固定为 `AI-信息采集`。

## 数据源字段

每个 JSON 描述一个界面（截图），主要字段：

| 字段 | 用途 |
| --- | --- |
| `module` | 模块名；缺失时用功能目录路径推断 |
| `func` | 功能名；缺失时用 `desc` 首行或 JSON 文件名 |
| `desc` | 人工描述（可空） |
| `interface_desc` | 视觉识别：界面整体描述 |
| `layout_desc` | 视觉识别：布局描述 |
| `elements_desc` | 视觉识别：元素列表；支持对象 `{name, description}` 或字符串 |
| `img` | 截图相对路径，如 `img/screenshot_001.png` |

不读取 `content` / `raw_content` / `page_url` / `page_title` 字段。

## 分析原则

- 只写当前 `func` 的专属测试点。
- 菜单栏、工具栏、状态栏、任务栏、托盘图标、登录态入口等公共元素只引用全局公共模块，不在每个页面重复展开。
- 不把其他业务功能写入当前功能文档。例如分析"登录"时，不展开"充值""个人中心"的业务测试点，只把它们识别为全局导航入口。
- 不臆造后端接口、数据库、具体路由实现或不存在的业务规则。
- 优先从 `interface_desc` / `layout_desc` / `elements_desc` 提取测试点，并结合截图判断。
- 每个测试点必须包含"操作"和"预期"；有输入时补充"数据"。

## 安卓补充原则

- 系统能力：状态栏、信号/Wi-Fi、电量、通知中心、控制中心、横竖屏、暗黑/亮色模式、字体大小、勿扰、权限弹窗（相机/相册/位置/通讯录/麦克风/通知/电话 等）。
- 系统交互：物理返回/手势返回/导航条返回、Home 键、多任务切换、应用切换、杀进程重启恢复、后台切前台、长按、平台特有手势。
- 输入能力：中文/英文/数字/符号、输入法切换、表情、语音输入、自动填充、密码管理器、自动联想、复制粘贴。
- 网络与异常：飞行模式、弱网/断网重连、切换 Wi-Fi/蜂窝、VPN、低延迟场景、推送（厂商通道/FCM）与本地通知。
- 生命周期：冷启动、热启动、首次安装、升级覆盖安装、清除数据、登出登入、跨设备同步、消息推送点击进入指定页。
- 安全与隐私：截屏限制、指纹/人脸/数字密码、生物识别失败回退、敏感信息遮罩、后台脱敏、权限运行时申请。
- 多端差异：在 H5/Web/桌面端有差异的交互（桌面端多窗口/快捷键/右键菜单/拖拽；移动端手势/系统返回），需要在测试点中标注。
- 平台独有形态（如桌面小组件、Material You、后台管理、多窗口分屏、画中画）单独列出。



## 输出规则

- 页面测试点输出目录：`AI-测试点分析/<模块路径>/`，`<模块路径>` 与采集中 `AI-信息采集/{批次号}/<模块路径>/` 一致。
- 公共模块输出目录：`AI-测试点分析/全局通用功能/`。
- 公共模块文件名固定为 `00_全局通用模块.md`。
- 页面文件名：`{功能名}.md`，例如 `登录.md`。
- 每个最终 Markdown 文件必须以 `--- / convert: mindmap / ---` 开头。
- 只使用一个 `#` 一级标题作为中心主题。
- 使用 `##`、`###`、`####` 和 `-` 列表表达层级，不使用 Markdown 表格作为主体结构。
- 截图路径必须使用从输出文档到截图文件的相对路径（通常需要 `../../AI-信息采集/<批次号>/<模块路径>/img/...`）。

## 公共模块策略

- 指定批次中有 2 个及以上页面共享相似状态栏、TabBar、登录状态入口、侧边栏或底部导航时，生成全局公共模块文档。
- 只分析单个页面且无法确认公共性时，可以在页面文档中写"本批次未单独生成全局公共模块"，不要展开大量公共测试点。
- 公共模块的"登录状态变化"必须覆盖未登录/已登录两种态；安卓端额外覆盖多账号切换。
- 页面文档引用公共模块时，按页面文档位置计算到 `AI-测试点分析/全局通用功能/00_全局通用模块.md` 的相对路径。
- 如果跨多个模块生成文档，仍然只维护项目级的公共模块文档，不要在每个模块目录重复生成公共模块。

## 常见页面补充项

- 登录页：账号为空、格式错误、未注册账号、密码为空、密码边界、错误密码、自动登录、重复点击、第三方登录、验证码、密码显示规则、记住密码、登录成功跳转、失败提示、首次登录引导。
- 注册页：账号为空/已存在、格式错误、密码为空、密码长度边界、确认密码不一致、验证码为空/错误/过期/刷新、协议勾选、注册成功/失败、引导完善资料。
- 搜索页：关键词为空、特殊字符、超长关键词、有结果、无结果、分页、搜索历史、热词推荐、搜索入口跳转、清除搜索、高级筛选。
- 列表页：初始列表、空状态、单页、多页、翻页边界、筛选无结果、排序切换、列表项双击/右键、列表项拖拽、下拉刷新（移动端适用时）、错误重试。
- 设置页：通知设置、隐私设置、主题/暗黑模式、字体大小、语言切换、清除缓存、退出登录、版本更新、关于我们、快捷键自定义。
- 高风险操作：上传、下载、支付、删除等必须覆盖权限、确认弹窗、失败回滚、重复操作、异常中断、关闭窗口中断。

## 自检规则

- 文件开头包含 `convert: mindmap`。
- 文档层级清晰，主体没有表格。
- 截图相对路径可从 Markdown 文件位置打开。
- 页面文档没有把全局菜单、工具栏或其他功能的测试点展开为当前功能测试点。
- 功能测试点、状态测试点、边界条件、业务跳转均已覆盖。
- 安卓特有测试点（系统返回、状态栏、权限、生命周期 等）已覆盖。
- 未臆造接口、数据库、代码实现或不可见路由。
